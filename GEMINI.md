# Instruções Persistentes do Sistema (GEMINI.md)

## Regra Obrigatória: Prática "classe-para-humanos"
Todos os elementos relevantes como containers, componentes, menus, painéis, modais, toolbars e cartões devem adotar classes descritivas simbólicas para humanos (ex: `container-canva-mapa-br`, `container-mapa-br`, `painel-toolbar-relevo`, `painel-guardiao-detalhes`, `pin-brasao-estado`, `menu-superior-status`).
